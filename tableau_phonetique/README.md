Quick tips pour prendre en main les fichiers

Le tableur est l'une des créations centrales de Phonétique post-binaire. Il répertorie les voix de 6 personnes différentes décomposées en 3 textes et comportant 26 mots post-binaires au total. Ces textes ont été écrits via 3 systèmes typographiques (ligatures, diacritique et epsilon) et 2 grammaires (Acadam et Système Al). 7 typographies ont été éprouvées à la lecture pendant ce projet (Adelphe, BBB Baskervool, BBB DM Sans, Enby Gertrude, BBB Herthey Futural, BBB Open Sans et BBB Readme).

Ce tableur est donc très fourni. Il sert d'archive visuelle et lie le texte aux audios. Les éléments sont hiérarchisés de manière élémentaire, il est donc peut-être nécessaire d'avoir quelques explications supplémentaires pour bien le comprendre et s'en emparer.

Les 5 premières colonnes décomposent les mots post-binaires utilisés dans les différents textes.

Colonnes B-F :

Colonne B : Mots provenant des textes originaux, masculin/féminin
Colonne C : Déterminants grammaticaux des mots
Colonne D : Terminaisons des mots, masculin/féminin
Colonne E : Traduction des mots provenant des textes originaux en langage post-binaire, liés à leurs typographie
Colonne F : Terminaison des mots post-binaires, liés à leurs typographie
Les 12 dernières colonnes retranscrivent textuellement les enregistrements.

Colonnes G-R :

Colonne G : Mots post-binaires entendus, liés à leurs typographie
Colonne H : Traduction des mots post-binaires via le système API
Les 10 autres colonnes reprennent le même système avec les 5 autres personnes enregistrées.

Les rangées sont décomposées en fonction des typographies choisies, puis se divisent en 3 textes différents.

Rangées 3-36 : BBB Open Sans

Rangées 6-15 : Bastard out of Carolina, Dorothy Allison
Rangées 17-21 : Exercice de prononciation 1
Rangées 23-36 : Exercice de prononciation 2
Le tableur se poursuit sur le même modèle mais avec des typographies différentes.

Typographies utilisées :

Ligatures : BBB Open Sans / BBB Readme / BBB Herthey Futural / Enby Gertrude / BBB DM Sans / BBB Baskervool
Diacritiques : BBB Open Sans / BBB Readme / Adelphe / BBB Herthey Futural
Epsilons : BBB Open Sans / BBB Readme / Adelphe / BBB Herthey Futural
Grammaires (Acadam + Système Al) : BBB Readme
